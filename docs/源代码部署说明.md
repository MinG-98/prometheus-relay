# 源代码部署说明

Prometheus Relay 推荐使用 [Docker 部署](docker-deployment.md)。只有本地开发、任务面板或不便使用 Docker 时，才建议直接运行源码。

## 环境要求

- Python 3.11 或更高版本
- Chromium 及 Playwright 所需系统依赖
- 可访问抖音创作者中心的网络

## 安装

```bash
git clone https://github.com/MinG-98/prometheus-relay.git
cd prometheus-relay
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
playwright install chromium --with-deps --only-shell
```

## 配置

复制环境变量示例并填入自己的任务信息：

```bash
cp .env.example .env
editor .env
```

`.env` 包含账号 Cookie，已经被 `.gitignore` 排除。仍应将文件权限设为仅当前用户可读，并避免通过聊天或公共网盘传输。

## 运行

```bash
python main.py
```

如需网页控制台、每日调度和运行历史，请使用 Docker 部署方式。
